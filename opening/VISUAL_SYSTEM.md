# Direção visual — mapa provisório (EP300 Cinema Opening)

> **Não cristalizar.** Isto é um mapa provisório para trabalhar enquanto o site do
> EP300 (Claudio + Lucian) não chega. Quando o site chegar, o passo seguinte é a
> **gramática de motion** completa (inventário de componentes, tokens, comportamentos
> — ver checklist abaixo), não uma continuação incremental deste documento.

## O que já está definido (nível de tom, confirmado com o Gabriel em 2026-09-22)

- Direção geral: **colagem/documentário** com leveza (ref. Johnny Harris) — tom
  comemorativo, não solene, não emotivo.
- Números grandes: tratados como **marca-texto laranja MB + circulado à mão**
  (ref. `oagentico-papel-colagem`), nunca como stat card corporativo.
- Cold open: cru, sem tratamento — contraste proposital com o resto do vídeo.
- Referências relacionadas no banco de refs do Studio: `johnny-harris-vox`,
  `gaveta`, `chef-otto`, `joao-curry`, `thomas-frank-nerdologia`,
  `oagentico-papel-colagem`.

## O que explicitamente NÃO fazer

- Não é "fazer um Spotify Wrapped". O site é conceitualmente próximo, mas a
  linguagem final deve vir da experiência real construída para o EP300, não de uma
  referência genérica de mercado.
- Não são "screenshots animados" do site — o objetivo final (quando o site chegar)
  é traduzir EXPERIÊNCIA DIGITAL → EXPERIÊNCIA AUDIOVISUAL, não capturar a tela.

## Quando o site chegar — checklist de tradução

1. Inspecionar a experiência real.
2. Inventariar componentes (cards, botões, stickers dos apresentadores, telas).
3. Identificar padrões e tokens visuais (se existirem).
4. Separar elementos estruturais de decorativos.
5. Identificar assets reutilizáveis vs. o que precisa adaptação.
6. Identificar comportamentos/interações (como cards entram, como números
   aparecem, como botões se comportam, como stickers aparecem, como telas se
   conectam, ritmo, escala, profundidade, tipografia em movimento, convivência
   apresentadores × interface).
7. Identificar o que **não** funciona em vídeo (interação não se traduz 1:1 para
   narrativa linear) e como adaptar.
8. Consolidar tudo isso como **gramática de motion** — documento novo
   (`MOTION_SYSTEM.md`, ainda não criado: não há conteúdo real para colocar nele
   antes do site chegar).

> Sinalizado no pedido original: esta fase (tradução experiência → gramática de
> motion) já justifica orçamento de raciocínio maior (Opus/high effort) para
> direção visual e exploração criativa — não é trabalho mecânico.

## Ideias visuais existentes = hipóteses pré-site, não direção aprovada

As ideias de insert já registradas em `wiki/concepts/ep300-roteiro-edicao.md` (placar,
contador, grades, split screen, replay stack, grid de logos, mapa-múndi etc.) foram
criadas em 2026-09-22, **antes** da decisão (2026-09-26) de usar o site do EP300 como
referência visual principal. O Studio (`#/ep300`) agora rotula essa seção como
"hipóteses pré-site" — não apagadas, não implementadas, só reclassificadas. Quando o
site chegar, cada uma passa pelo crivo do checklist acima (ainda faz sentido? o site
resolve melhor? precisa adaptar? entra em conflito?) antes de virar direção real.
